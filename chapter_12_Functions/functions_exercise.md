# Functions Exercises

Solve these questions in JavaScript. Focus on reusable functions, clear parameters, return values, and interview explanations.

## Function Basics

1. Write a function to print your name.
2. Write a function to add two numbers.
3. Write a function to subtract two numbers.
4. Write a function to multiply two numbers.
5. Write a function to divide two numbers.
6. Write a function to check even or odd.
7. Write a function to check voting eligibility.
8. Write a function to calculate simple interest.
9. Write a function to convert Celsius to Fahrenheit.
10. Write a function to return the square of a number.

## Parameters And Return Values

1. Write a parameterized function to greet a user by name.
2. Write a function that accepts marks and returns grade.
3. Write a function that accepts age and returns ticket price.
4. Write a function that accepts price and discount and returns final price.
5. Write a function that accepts username and password and returns login status.
6. Write a function that accepts an array and returns its sum.
7. Write a function that accepts a string and returns vowel count.
8. Write a function that accepts two strings and checks if they are equal after trimming and ignoring case.
9. Write a function that accepts a number and returns factorial.
10. Write a function that accepts a number and returns whether it is prime.

## Function Types

1. Write one function declaration example.
2. Write one function expression example.
3. Write one arrow function example.
4. Convert a function declaration into a function expression.
5. Convert a function expression into an arrow function.
6. Write an arrow function with implicit return.
7. Write an arrow function that returns an object.
8. Write a named function expression for factorial.
9. Write a function with default parameters.
10. Write a function with rest parameters.

## Callback And Higher Order Functions

1. Write a calculator function that accepts another function as operation.
2. Write a function that accepts a callback and calls it after printing a message.
3. Use callback with `map` to double numbers.
4. Use callback with `filter` to get failed test cases.
5. Use callback with `reduce` to calculate total execution time.
6. Write a higher order function that returns a multiplier function.
7. Write a higher order function that repeats a task `n` times.
8. Write a function that accepts validation rules as callbacks.
9. Write a function that accepts test cases and a callback to filter by status.
10. Write a function that accepts API responses and a callback to validate each response.

## Scope, Closure, And IIFE

1. Demonstrate global scope and function scope.
2. Demonstrate block scope using `let` and `const`.
3. Write a closure that creates a counter.
4. Write a closure that remembers a user role.
5. Write a closure that creates a private balance variable.
6. Write an IIFE that prints a message immediately.
7. Write an IIFE that keeps a variable private.
8. Explain why closures are useful in JavaScript.
9. Explain why `var` behaves differently from `let` inside loops.
10. Explain lexical scope with one code example.
