# Conditional Statements Exercises

Solve these questions in JavaScript. Focus on readable conditions, correct edge cases, and avoiding unnecessary nesting.

## Basics

1. Check whether a number is positive, negative, or zero.
2. Check whether a number is even or odd.
3. Check whether a person is eligible to vote.
4. Check whether marks are pass or fail.
5. Print the greatest of two numbers.
6. Print the greatest of three numbers.
7. Check whether a year is a leap year.
8. Check whether a character is a vowel or consonant.
9. Check whether a number is divisible by both 3 and 5.
10. Check whether a number is a three-digit number.

## Else If And Nested If

1. Create a grading system based on marks.
2. Calculate electricity bill based on unit slabs.
3. Check login access using username and password.
4. Check ATM withdrawal rules: sufficient balance and amount multiple of 100.
5. Check loan eligibility using age, salary, and credit score.
6. Check ticket price based on age group.
7. Check shipping charge based on cart value and membership.
8. Check whether a triangle is equilateral, isosceles, or scalene.
9. Check whether three sides can form a valid triangle.
10. Check whether a user can access admin, editor, or viewer dashboard.

## Switch Statement

1. Print day name from day number.
2. Print month name from month number.
3. Create a simple calculator using `+`, `-`, `*`, `/`, and `%`.
4. Print traffic light action for red, yellow, and green.
5. Print order status message for pending, shipped, delivered, and cancelled.
6. Print browser type for chrome, firefox, edge, and safari.
7. Print test priority for P0, P1, P2, and P3.
8. Print defect severity for blocker, critical, major, minor, and trivial.

## Interview Questions

1. Explain the difference between `==` and `===` with examples.
2. Explain truthy and falsy values in JavaScript.
3. What is the difference between `if else` and `switch`?
4. What happens if `break` is missing in a `switch` case?
5. Rewrite a nested ternary condition using `if else`.
6. Rewrite an `if else` grading solution using ternary operator.
7. Find the output when condition contains assignment by mistake: `if (x = 10)`.
8. Find the output of `if ("false")`.
9. Find the output of `if ([])`.
10. Find the output of `if (null)`.

## QA Style Practice

1. Write conditions to validate mandatory fields in a login form.
2. Write conditions to validate minimum and maximum password length.
3. Write conditions to decide whether a test case is smoke, sanity, or regression.
4. Write conditions to classify API status codes into success, client error, and server error.
5. Write conditions to decide whether a bug should be reopened.
6. Write positive and negative test cases for a coupon discount condition.
7. Write boundary test cases for age-based eligibility.
8. Write equivalence classes for marks-based grade calculation.
