# Arrays Exercises

Solve these questions in JavaScript. Focus on array methods, manual loop solutions, and explaining tradeoffs in interviews.

## Basics

1. Create an array of marks and print all marks.
2. Print the first and last element of an array.
3. Add an element at the end of an array.
4. Remove an element from the end of an array.
5. Add an element at the start of an array.
6. Remove an element from the start of an array.
7. Find the length of an array.
8. Update an element at a specific index.
9. Check whether a value exists in an array.
10. Copy an array without changing the original.

## Loop Based Questions

1. Find the sum of all numbers in an array.
2. Find the average of numbers in an array.
3. Find the maximum number in an array.
4. Find the minimum number in an array.
5. Count even and odd numbers in an array.
6. Reverse an array manually.
7. Remove duplicate values from an array.
8. Find the second largest number in an array.
9. Find missing number from an array containing numbers 1 to `n`.
10. Find common elements between two arrays.

## Array Methods

1. Use `map` to double every number.
2. Use `filter` to get only even numbers.
3. Use `reduce` to calculate total price.
4. Use `find` to get the first failed test case.
5. Use `some` to check whether any test failed.
6. Use `every` to check whether all tests passed.
7. Use `sort` to sort numbers in ascending order.
8. Use `slice` to copy part of an array.
9. Use `splice` to remove an item from the middle.
10. Use `flat` to flatten a nested array.

## Object Arrays

1. Find all students who scored more than 80.
2. Find the student with the highest marks.
3. Calculate average marks from an array of student objects.
4. Filter products with price greater than 1000.
5. Sort products by price.
6. Find a user by email.
7. Count test cases by status: passed, failed, skipped.
8. Group bugs by severity.
9. Extract only test case names from an array of test objects.
10. Find duplicate bug IDs from an array of bug objects.

## Interview Questions

1. Difference between `push` and `pop`.
2. Difference between `shift` and `unshift`.
3. Difference between `map` and `forEach`.
4. Difference between `filter` and `find`.
5. Difference between `some` and `every`.
6. Difference between `slice` and `splice`.
7. Why does default `sort()` give wrong result for numbers?
8. Difference between shallow copy and deep copy.
9. What is array destructuring?
10. What is spread operator in arrays?

## QA Style Practice

1. Given test results, return only failed test names.
2. Given API users, validate that every user has `id`, `name`, and `email`.
3. Given browser list, generate test combinations for each browser.
4. Given duplicate test case IDs, return unique IDs.
5. Given bug objects, return all critical open bugs.
6. Given response times, find tests taking more than 2 seconds.
7. Given expected and actual arrays, find missing values.
8. Given two arrays, compare whether both contain same values.
