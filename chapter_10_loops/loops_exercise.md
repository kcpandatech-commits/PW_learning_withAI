# Loops Exercises

Solve these questions in JavaScript. Focus on loop control, dry runs, edge cases, and choosing the right loop.

## Basics

1. Print numbers from 1 to 10.
2. Print numbers from 10 to 1.
3. Print even numbers from 1 to 50.
4. Print odd numbers from 1 to 50.
5. Print the multiplication table of a number.
6. Find the sum of numbers from 1 to `n`.
7. Find the factorial of a number.
8. Count digits in a number.
9. Reverse a number.
10. Check whether a number is palindrome.

## Patterns

1. Print a square pattern of stars.
2. Print a right triangle pattern of stars.
3. Print an inverted right triangle pattern of stars.
4. Print a number triangle pattern.
5. Print a multiplication table from 1 to 10.
6. Print a pyramid pattern.
7. Print a diamond pattern.
8. Print a checkerboard pattern using `*` and spaces.

## Loop Control

1. Use `break` to stop a loop when number 7 is found.
2. Use `continue` to skip numbers divisible by 3.
3. Find the first number divisible by both 5 and 7 between 1 and 100.
4. Print all numbers except multiples of 4.
5. Stop processing an array when a failed test case is found.
6. Skip disabled test cases while printing test names.
7. Find the first duplicate number in an array.
8. Find the first character that is repeated in a string.

## Arrays And Strings With Loops

1. Find the maximum number in an array.
2. Find the minimum number in an array.
3. Count positive and negative numbers in an array.
4. Count vowels in a string.
5. Reverse a string using a loop.
6. Check whether a string is palindrome using a loop.
7. Count words in a sentence without using `split`.
8. Remove duplicate values from an array using loops.
9. Merge two arrays using loops.
10. Find common values between two arrays.

## Interview Questions

1. Explain the difference between `for`, `while`, and `do while`.
2. When should you use `for...of`?
3. When should you use `for...in`?
4. What is an infinite loop? Give one example.
5. What is the difference between `break` and `continue`?
6. What is the time complexity of a nested loop?
7. Dry run a loop that calculates factorial.
8. Dry run a loop that reverses a number.
9. Explain why `i++` and `++i` usually behave the same in a loop increment section.
10. Explain why array length should be used carefully when modifying an array inside a loop.

## QA Style Practice

1. Loop through test results and count passed, failed, and skipped tests.
2. Loop through API response records and find missing mandatory fields.
3. Loop through a list of URLs and print only invalid URLs.
4. Loop through bug IDs and find duplicates.
5. Loop through test durations and find the slowest test.
6. Loop through browser names and generate cross-browser test titles.
7. Loop through form field names and validate that none are empty.
8. Loop through log lines and print only error messages.
